# Contrato de interação

Toda interação material define trigger, resultado, loading, sucesso, falha, foco, teclado, preservação de contexto, reset, efeito em paginação/seleção e navegação. Cubra filtros, sort, paginação, tabs, detalhe, ações, links, retry, seleção, período e drill-down quando aplicáveis.

Paginação define `pages`, `cursor` ou `load-more`, posição, page size, primeira página, total, reset por filtro, preservação de sort/detalhe, foco/scroll, loading, página vazia e labels acessíveis; nunca apenas `pagination: true`.
