# Conteúdo e copy

Não invente campo, indicador, cálculo, capacidade, regra ou estado. Defina títulos, subtítulos, labels, headers, captions, placeholders, helper text, mensagens, botões, links e nomes acessíveis quando o significado já estiver decidido.

Precedência: texto exato do sponsor; texto exato de decisão aprovada; significado decidido sem copy (escreva wording claro); wording que altera significado (clarifique); conceito inexistente (não invente). Registre origem/status no inventário visível.
