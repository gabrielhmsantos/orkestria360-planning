# Grupos Dinâmicos — Decisões

- Um grupo dinâmico é identificado por `DynamicMembership`; estado de processamento e regra são evidências centrais — `Microsoft365_Grupos.docx`.
- A capacidade é `restricted` por Microsoft Entra ID P1/P2.
- Crescimento abrupto e regra ampla são sinais sugeridos, não achados automáticos enquanto as regras não forem homologadas.
