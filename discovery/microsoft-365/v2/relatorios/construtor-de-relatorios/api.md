# APIs — Construtor de Relatórios

Não há rota externa. O Construtor guiado não consulta Graph, arquivos ou fontes em tempo de tela.

## Uso pela aplicação

Resultado: **projeção local**. O preflight consulta templates/blocos aprovados e publicações atuais; após aceite, prévia e geração consultam somente o manifesto congelado da solicitação. Não há contrato de upload, compartilhamento ou exportação externa neste discovery.
