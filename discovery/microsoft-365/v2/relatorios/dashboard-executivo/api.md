# APIs — Dashboard Executivo / Relatórios

Não há rota externa própria nesta superfície. Os fatos são consumidos de projeções locais publicadas pelos módulos Microsoft 365; o Dashboard não faz chamada Graph.

## Uso pela aplicação

Resultado: **projeção local**. A tela compõe somente fontes que já publicaram disponibilidade, cobertura, frescor e período. Service health, quando disponível, permanece fonte canônica separada; custo/economia e IMDO sem publicação ficam indisponíveis.
