# APIs — Catálogo de Relatórios

Não há rota Microsoft externa nesta superfície. O catálogo é metadado local de templates e requisitos; não verifica permissão, licença ou disponibilidade por chamada em tela.

## Uso pela aplicação

Resultado: **projeção local**. A disponibilidade deriva de requisitos do template e source states/publicações atuais da mesma tenant+conexão, não de manifestos locais de execuções passadas. O card restrito informa requisito publicado, sem revelar configuração de conexão ou tentar uma leitura externa.
