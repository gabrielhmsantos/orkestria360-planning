# APIs — Dashboard Executivo

Não há chamada Graph ou Azure da superfície. O dashboard consome exclusivamente as projeções publicadas das demais abas, incluindo disponibilidade, cobertura, frescor e razão por fonte.

## Uso pela aplicação

Configuration Score, contagens e relatórios são cálculos e leituras de dados do Orkestria. Exportar relatório não introduz chamada externa nem operação de escrita no Microsoft 365.
