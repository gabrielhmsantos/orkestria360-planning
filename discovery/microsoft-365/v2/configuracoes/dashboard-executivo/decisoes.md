# Dashboard Executivo — Decisões

- Configuração conforme compara diretamente valor atual e baseline; divergente é o valor diferente do baseline — sponsor.
- O score usa os nove pesos definidos e domínio sem coleta contribui zero; cobertura ponderada acompanha a nota — Q: fórmula e ausência no Configuration Score → A: C (origem: usuário; data: 2026-08-24).
- Clarificação — Q: contribuição de linha homologada sem leitura comparável → A: a linha permanece `unavailable`, não é marcada conforme nem divergente, mas entra no denominador com contribuição `0`; reduz nota e cobertura. Travas seguem inativas sem fato positivo de risco (origem: usuário; data: 2026-08-25).
- Travas de controles críticos impedem “Excelente”, mas não mudam a nota numérica — decisão do usuário baseada nas travas do sponsor.
- Clarificação — Q: classificação do Configuration Score → A: B (`0–59` Crítico; `60–74` Atenção; `75–89` Bom; `90–100` Excelente; trava rebaixa somente Excelente para Bom) (origem: usuário; data: 2026-08-25).
- Clarificação — Q: escopo das travas do score na primeira versão → A: somente as sete travas deriváveis de fatos Microsoft 365 homologados; alteração crítica não aprovada e drift crítico não investigado permanecem observáveis, mas não bloqueiam classificação (origem: usuário; data: 2026-08-25).
