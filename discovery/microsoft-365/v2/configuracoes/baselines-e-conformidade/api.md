# APIs — Baselines e Conformidade

Não há endpoint Microsoft Graph ou Azure próprio da superfície. Baselines e comparações usam a matriz local homologada e os estados normalizados já publicados pelas fontes de configuração.

## Uso pela aplicação

A comparação é leitura local de valor atual, baseline, cobertura e frescor. Nenhuma ação externa, criação ou alteração de baseline é parte deste módulo.
