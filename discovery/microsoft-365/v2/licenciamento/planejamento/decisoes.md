# Decisões — Planejamento

- Graph confirma o SKU existente, mas não é fonte de calendário, preço, projetos, admissões ou orçamento.
- Cenários são isolados, versionados e não modificam contratos nem tenant.
- Recomendações estratégicas são consultivas; devem declarar premissas e não ser apresentadas como fato técnico.
- Solicitações comerciais e workflow ficam fora da V2; seus controles exibem “Em breve”.
- O roadmap V2 associa etapa, dependências e benefício técnico; prazo e investimento dependem de dados futuros.
- Produtos fora do Microsoft 365/Graph (Windows Server, SQL Server, CAL/RDS, Azure e similares) ficam para fase futura via Assessment/CSV ou fonte comercial apropriada.
