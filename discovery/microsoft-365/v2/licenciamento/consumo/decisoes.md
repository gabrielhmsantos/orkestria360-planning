# Decisões — Consumo

- Janelas de 7, 30 e 90 dias são parâmetros explícitos; o padrão de ociosidade inicial é 90 dias.
- A classificação considera exceções cadastradas, contas técnicas, contingência, afastamento e projetos.
- Atividade geral não prova uso de cada recurso premium; métricas específicas devem complementar o relatório geral quando disponíveis.
- Totais anonimizados podem ser exibidos, mas o usuário individual só aparece quando a configuração de relatório permitir identificação.
- Histórico superior ao período oferecido pela Microsoft depende de snapshots próprios diários.
